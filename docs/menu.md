# OLED 资源菜单

Demo 使用 [arduino-oled-menu](https://github.com/lsongdev/arduino-oled-menu) 的 `oledmenu::Menu` Arduino 库，版本固定在 `platformio.ini`。启动后显示 11 项菜单，一次只运行选中的功能；每项功能的进入、更新、操作和退出在独立模块中实现。

```sh
pio run -e demo -t upload --upload-port /dev/ttyACM0
pio device monitor --port /dev/ttyACM0
```

默认 `matrixbit` 环境仍是简单资源 API 示例，生命周期管理属于 `demo` 环境。

## 操作

短按在释放时触发，按键消抖 25 ms；长按 650 ms 触发一次，释放后不会再次触发短按。

| 位置 | A 短按 / 长按 | B 短按 | B 长按 |
| --- | --- | --- | --- |
| 主菜单 | 下一项 / 上一项，循环选择 | 启动选中的功能 | 保持菜单 |
| 功能内 | 执行本功能的下一项 / 上一项操作 | 执行本功能的操作 | 停止功能，返回菜单 |

返回后保留菜单选中位置。功能内不直接跳转到其他资源页面；先返回，再选择其他功能。重新进入会初始化该功能的状态。

串口输入也走同一套生命周期：`n` / `p` 对应 A 短按 / 长按，`o` 对应 B 短按，`b` 退出功能；`w` 先退出当前功能，再进入 Wi-Fi。

## 功能

| 菜单项 | 进入后 | 操作 | 退出时 |
| --- | --- | --- | --- |
| Status | 显示运行时间、堆内存、CPU、Flash 和 I2C 错误计数 | 无额外操作 | 停止页面刷新 |
| OLED | 显示屏幕测试 | A 切换文字、全亮、棋盘格；B 切换反色 | 恢复正常显示 |
| IMU | 初始化 QMI8658，采集加速度、角速度和温度 | 无额外操作 | 停止采样，关闭加速度计和陀螺仪采集 |
| Magnetometer | 初始化磁力计，定时进行单次测量 | 无额外操作 | 停止测量，清除就绪状态 |
| Light | 定时读取光线 ADC | 遮挡传感器观察原始值 | 停止 ADC 读取 |
| Microphone | 采样麦克风，显示 100 ms 窗口的峰峰值 | 拍手观察原始值 | 停止采样，清除窗口状态 |
| Touch | 定时读取六个触摸焊盘的原始计数 | 触摸焊盘比较变化 | 停止读取 |
| RGB LEDs | 启动三色和单颗白灯循环 | A 前进 / 后退颜色；B 重启循环 | 关闭全部灯珠，释放数据引脚 |
| Buzzer | 初始化并播放 880 Hz、100 ms 短鸣 | B 再次播放 | 停止发声，解除 LEDC 引脚绑定 |
| IO control | 默认将 GPIO26 设为低电平输出 | A 选择下一引脚，长 A 选择上一引脚，B 切换高 / 低电平 | 拉低当前引脚，再释放为输入 |
| Wi-Fi | 打开无线并异步扫描 | A 浏览 SSID，长 A 反向浏览，B 重新扫描 | 取消未完成扫描，清除结果和回调，关闭无线 |

主菜单不会继续采样 ADC、触摸、磁力计，也不会循环 RGB、播放蜂鸣器或扫描 Wi-Fi。共享的 OLED、按键和 I2C 保持可用，作为菜单界面。启动时会清除复位前可能保留的灯珠颜色，并关闭 IMU 采集。停止 ADC / 触摸读取不代表切断板载传感器的供电。

IMU 与磁力计初始化失败时显示不可用；尚无数据或数据超过 1.5 秒未更新时显示等待，不沿用上次进入时的数据。

## IO 控制

可选 GPIO 为 `18、19、21、25、26、32、33`，使用 ESP32 GPIO 编号。列表避开 GPIO6–11 的 Flash 接线、启动配置引脚，以及本项目使用的 OLED、按键、触摸、RGB、蜂鸣器和模拟输入引脚。引脚是否引出到具体触点应按实板接线确认；兼容 mPython 的 P8 → GPIO26 映射尚未实测。

进入和切换到新引脚时均先设置低电平，再启用输出。原引脚在切换或退出时先拉低，然后设为输入；输入状态的实际电平由外部电路决定。每次重新进入恢复 GPIO26、LOW。

## Wi-Fi 扫描

结果最多保存 24 条，按扫描器的默认顺序显示。当前条目显示 RSSI（dBm）与 OPEN / LOCK；SSID 最多显示 20 个字符，隐藏网络显示 `<hidden>`。默认字体不支持中文 SSID，完整名称输出至串口。

扫描失败、超时（20 秒）或没有网络时会提示，可按 B 重试。扫描期间长按 B 返回会取消扫描；返回后不会在后台继续扫描。扫描完成后清除框架缓存，将无线保持在页面内可用的状态；退出才关闭无线。该功能不连接网络或保存密码。

## 实现和验证

- `src/demo.cpp`：菜单登记、按键和串口事件、进入与返回、屏幕刷新。
- `src/demo/features.h`：功能接口和单一活动功能的生命周期管理。
- `src/demo/*.cpp`：每个功能的状态、采样、绘制、进入与退出。
- `include/menu_assets.h`：Adafruit GFX 位序的 16×16 图标。
- `tests/demo_lifecycle.cpp`：主机测试，覆盖功能替换、退出后停止更新，以及 IO 高电平退出、引脚切换和重新进入。

运行主机测试：

```sh
g++ -std=c++11 -Wall -Wextra -Werror -Isrc -Itests/stubs \
  tests/demo_lifecycle.cpp src/demo/io.cpp -o /tmp/matrixbit-demo-lifecycle
/tmp/matrixbit-demo-lifecycle
```

主机测试替代 GPIO 驱动，验证调用顺序和状态变化；实际引脚电平及功能退出效果仍需实板确认。上游菜单提交、图标来源和 MIT 许可见 `third_party/arduino-oled-menu`。
